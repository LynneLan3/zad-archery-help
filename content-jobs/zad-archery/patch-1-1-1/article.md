# Zad Archery Patch 1.1.1 (Sep 5): Guardian Skip and Portal Currency Fixes

Quick Answer

Patch 1.1.1 is the September 5 follow-up to the Mega Update. It adds an Effects Amount slider, auto-collects piled mining ore, fixes currency UI wrapping, repairs the Run Portal death skip that could skip monsters or a Guardian, restores missed Guardians or grants their currency if already passed, stops leftover skill effects from killing the next Run Portal, and corrects lost Portal Currency from the skipped-level bug on load.

## Effects Amount slider added
An Effects Amount slider has been added to the game. This option adjusts effects amount (no further values or UI specifics were provided in the notes).

## Mining ore auto-collect
Mining ore will now auto-collect when too much ore piles up, preventing ore from remaining uncollected due to pile limits.

## Currency UI wrap fix
The currency UI wrapping issue has been fixed so currency display no longer wraps incorrectly (no additional UI changes were detailed).

## Run Portal death skip repaired
Dying at the same moment a Run Portal dies no longer causes the next level to skip monsters or skip a Guardian encounter.

## Missed Guardian restoration or currency grant
If a Guardian was missed because of the previous skip bug, the Guardian can appear on the next level. If you already passed the point where that Guardian would appear, the Guardian is counted defeated and the appropriate currency is granted.

## Leftover skill effects no longer kill the next Run Portal
Leftover skill effects that previously could kill the next Run Portal have been fixed so they no longer cause that behavior.

## Lost Portal Currency corrected on load
Players who lost Portal Currency because of the skipped-level bug should find that their lost Portal Currency is corrected when the game is loaded.

## FAQ

Q: When was Patch 1.1.1 released?
A: Patch 1.1.1 was released on September 5 as a follow-up to the Mega Update.

Q: Does this patch fix the Run Portal skip that could skip a Guardian?
A: Yes. Dying as the Run Portal dies no longer causes the next level to skip monsters or a Guardian.

Q: What happens if I already passed the point where a missed Guardian would reappear?
A: If you already passed that point, the missed Guardian is counted defeated and the Guardian's currency is granted.

Q: Will I get back Portal Currency lost to the skipped-level bug?
A: Lost Portal Currency from the skipped-level bug is corrected on load.

Q: Are there UI or collection quality-of-life changes?
A: Yes. The patch adds an Effects Amount slider, fixes currency UI wrapping, and makes piled mining ore auto-collect when too much accumulates.
