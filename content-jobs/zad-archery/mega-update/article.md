# Zad Archery Mega Update (Sep 4): Symbols, Rings, Preferred Job and Endless

Quick Answer
The September 4 Mega Update is the current major content jump after launch. It adds the Symbol System (50+ Symbols and Exalted Symbols), Preferred Job, the Ring System with Portal Currency after level 30 and 9 Ring perks, Endless farming, and removes the Level 50 cap. September 5 Patch 1.1.1 is the follow-up stability patch.

## Symbol System
- A new Symbol System was added in the Sep 4 Mega Update.
- It includes 50+ Symbols and introduces Exalted Symbols.
- For a full system overview (slots, unlocks, and interactions) see the Symbols guide: /guides/progression/symbols/
- Do not rely on this page for unverified symbol rankings; consult the Symbols guide for details.

## Preferred Job
- Preferred Job is a new player-selectable setting added by the update.
- When you set a Preferred Job it doubles all bonuses of that preferred job.
- Use the in-game UI and the progression guides to learn how Preferred Job interacts with other systems.

## Ring System and Portal Currency
- A Ring System is added with nine Ring perks available.
- Portal Currency is introduced and used after level 30 (Portal Currency becomes relevant once you pass level 30).
- See the Rings / Portal / Endless guide for overview and how Ring perks and Portal Currency interact: /guides/progression/rings-portal-endless/
- This page does not provide unverified Ring rankings or hidden value numbers.

## Endless farming
- Endless farming mode is added in this update as a farming option.
- For practical Endless-mode strategies and details, consult the Rings / Portal / Endless guide: /guides/progression/rings-portal-endless/

## Level cap removal
- The update removes the Level 50 cap. Players can progress beyond the previous cap after this update.

## Quality-of-life: Automatic currency pickup and progression behavior
- The update improves automatic currency pickup.
- Progression-related behavior has been improved (general fixes to how progression and pickups behave).

## September 5 Patch 1.1.1 — stability fixes and Guardian skip recovery
Patch 1.1.1 (Sep 5) follows the Mega Update and fixes multiple stability and progression issues. Notable fixes:
- Effects Amount slider added to settings.
- Mining ore auto-collect fixes when too much ore piles up.
- Currency UI wrapping issues corrected.
- Fix for dying while a Run Portal dies that previously caused the next level to skip monsters / Guardian.
  - Missed Guardians can now appear on the next level.
  - If the player already passed the missed Guardian, the Guardian is counted as defeated and the corresponding currency is granted.
- Leftover skill effects no longer instantly kill the next Run Portal.
- Lost Portal Currency from the skipped-level bug is corrected on load.
For the full Patch 1.1.1 notes, see: /updates/patch-1-1-1/
