# Zad Archery Missing Guardian or Skipped Level: Patch 1.1.1 Recovery

Quick Answer
If a level skipped monsters or a Guardian after dying as the Run Portal died, Patch 1.1.1 is the fix. A missed Guardian can appear on the next level; if you already passed that point, the Guardian is counted defeated and currency is granted. Lost Portal Currency from the skipped-level bug is corrected on load.

## Before Patch 1.1.1 — what happened
1. Dying at the same moment the Run Portal died could cause the next level to skip monsters or the Guardian.
2. Leftover skill effects could also kill the next Run Portal, contributing to skipped content and progression gaps.

## What Patch 1.1.1 fixes
- The skip caused by dying as the Run Portal died is fixed.
- Leftover skill effects no longer kill the next Run Portal.
- Lost Portal Currency from the skipped-level bug is corrected when you load the game.

## How recovery behaves in a run (official behavior)
1. If the game skipped a Guardian because the Run Portal died as you died, that missed Guardian can appear on the next level.
2. If you already passed the relevant point on the next level before the fix could spawn the Guardian, the game treats the Guardian as defeated and grants the appropriate Portal Currency.
3. Any Portal Currency lost due to the skipped-level bug will be corrected on load (the game restores the missing currency when the save is loaded).

## Notes and limits
- This page only restates the official Patch 1.1.1 recovery behavior. It does not provide or invent additional manual workarounds beyond the official notes.
- All points above describe the recovery behavior as described in Patch 1.1.1; if you continue to see issues after updating, consult official patch notes or update announcements for further guidance.

## FAQ

Q: Will I get Portal Currency I lost because a level skipped the Guardian?
A: Yes. Lost Portal Currency from the skipped-level bug is corrected on load.

Q: If a Guardian was missing, will it reappear?
A: A missed Guardian can appear on the next level. If you already passed that point, the game counts the Guardian as defeated and grants the currency.

Q: Could leftover skill effects still kill the next Run Portal after the patch?
A: No. Patch 1.1.1 prevents leftover skill effects from killing the next Run Portal.

A: No. This page only restates the official Patch 1.1.1 recovery behavior and does not invent extra manual workarounds.
