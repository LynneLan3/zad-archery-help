# Zad Archery search opportunity snapshot

## What the evidence says

- Google Trends evidence supplied by the user shows **very low current US search volume** for the exact game name relative to an established comparison game.
- Steam/Reddit activity is ahead of Google demand: launch-day users are already asking concrete questions.
- This makes the site an **early-demand capture** project, not a proven high-volume brand site yet.
- The first release should therefore answer real questions already visible in communities, not publish a generic 30-page wiki.

## Highest-confidence launch intents

1. **How long is Zad Archery?**
   - Official ~5 hour target.
   - Multiple launch-day community reports.
   - Explicit Steam discussion thread.

2. **Demo save/progress transfer**
   - Developer explicitly says demo save cannot carry.

3. **Steam Deck**
   - Official compatibility metadata is available and specific.

4. **Achievements**
   - Live list exposes names/unlocks, but count discrepancy must be disclosed/rechecked.

5. **Mobile**
   - Developer directly linked iOS/Android versions.

6. **Patch 1.0.2 / Guardian-King issues**
   - Official patch gives exact fixes.

## Intents that look attractive but are NOT research-ready

- best early build
- all jobs / unlock order
- skill tree priority
- mining routes / ore locations
- crafting recipes / best upgrades
- Guardian Perks / King strategy

These should remain hidden or marked research-pending until current-build screenshots/video prove the mechanics.

## SERP strategy

Do not optimize around invented high-volume assumptions. The current advantage is:
- game just released,
- specialist guide supply is still thin,
- community questions are appearing before broad Google demand.

Build the answer pages above, then use GSC queries after indexing to decide which gameplay systems deserve deep expansion.
