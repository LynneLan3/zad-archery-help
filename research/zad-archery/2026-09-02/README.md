# zad-archery-research

First formal research pack for `zadarchery.help`.

This pack is designed to be consumed by Codex / `game-wiki-starter` V4.

## Start here

1. `manifest.json`
2. `research-report.md`
3. `page-plan.json`
4. `guide-content/articles/`
5. `media-manifest.json`
6. `research-gaps.json`
7. `codex-handoff.md`

## Status meanings

- `READY`: evidence is sufficient to build the factual page now.
- `READY_WITH_LIVE_COUNT_NOTE`: publishable, but a dynamic fact must be dated/rechecked.
- `HOLD_GAMEPLAY_EVIDENCE`: do not publish until current-build gameplay evidence exists.
- `HOLD_CURRENT_BUILD_VERIFICATION`: demo/community evidence exists but full-release behavior must be checked.

## Key rule

Do not invent missing gameplay facts to fill the approved front-end.
